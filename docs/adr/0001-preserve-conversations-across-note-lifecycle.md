# Preserve conversations across the note lifecycle

SpeakSpace treats AI Conversations as independent user content rather than Note Attachments. Moving a Note to the Trash makes that Note unavailable as an AI source, restoring it reactivates the retained relationship, and permanently deleting it removes only the relationship; the Conversation and its messages remain. This deliberately replaces orphan-conversation cleanup because silently deleting dialogue would create irreversible data loss outside the action the user confirmed.
