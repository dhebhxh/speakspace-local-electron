Let me set the context before we go into the details. In the first half of the year,
we rewrote the entire transcription pipeline for voice notes, mainly to solve
three problems. Memory pressure on long recordings, unstable sentence
cementations when Chinese and English are missed in one utterance and task
extraction that assigned other people's action items to the users. After the
rewrite, peak memory during transcription drooped by roughly 40 percent.
The segmentation error became far less frequent and task ownership now goes
through a second review pass. For the second half of the year, we will shift to
our tension to retrieval. The plan is to merge keyword search and vector search
into a single hybrid recall path and then order the result with reciprocal
rank fusion. The hard part is not algorithm itself, but the limited compute
bucket on local devices. The embedding model has to stay small without
scarification recall quality in Chinese. There is also a problem that is easy to
overlook, which is that latency for full library search growth accumulates
thousands of nodes. So we need to incremental indexing and caching strategy
well before that point.
