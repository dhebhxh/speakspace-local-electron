# 任务提取测试用例

## 一、基线：明确日期 + 明确任务

1. 单条任务，绝对日期

九月四号上午十点我要去参加那个供应商的评审会，地点在三号楼会议室。

预期：1 条，参加供应商评审会 → 2026-09-04

2. 多条任务，混合日期

这周的安排我说一下。周五之前把季度报表发给财务那边，下周一要交差旅报销的单子，
然后八月三十一号之前必须把服务器的续费办完，不然要停机。

预期：3 条 → 2026-08-21 / 2026-08-24 / 2026-08-31

二、相对日期（考日期推算）

3. 口语相对时间

明天早上记得给张经理回个电话，后天下午的培训我要提前半小时到，
下周三还得跟法务过一遍合同条款。

预期：3 条 → 2026-08-21 / 2026-08-22 / 2026-08-26

4. 模糊时间范围

这个月底前要把新人的入职材料整理好，下个月上旬安排一次团队复盘，
年底之前争取把这套流程文档补全。

预期：3 条，注意模型如何处理「上旬」「年底」这类区间

5. 周期性事项（考 CRITICAL RULE：不该拆成很多条）

从下周开始我每天早上九点半都要过一遍值班群的消息，每周五下班前发一次周报。

预期：2 条即可，不应该生成七条或一堆重复项

三、⭐ 冗余陷阱（专测 prompt 里的 RULE 1）

这三条是重点，模型很容易一个事件生成两条。

6. 事件日 + 提醒日

我下个月九月十号要去客户现场做汇报，麻烦提前三天提醒我准备材料。

预期：只有 1 条，日期是 2026-09-07（提醒日），不是两条

7. 截止日 + 提前量

投标文件的截止时间是九月十五号中午十二点，我打算提前一周就开始弄，
到时候九月八号那天记得叫我一下。

预期：只有 1 条 → 2026-09-08

8. 同一件事反复提

那个预算表的事啊…就是预算表，我得改一下预算表。周三之前改完就行，
对，就是那个预算的表格，别忘了。

预期：只有 1 条，不应该因为重复提及生成三条

四、⭐ 隐晦表达（不出现「任务」「提醒」「待办」等词）

9. 抱怨式待办

唉，李工那边的接口文档拖了快两周了，我这边一直卡着动不了。

预期：应识别出「催 / 跟进接口文档」类任务

10. 客户在等

客户那边还等着我们的报价呢，这都第三天了，人家昨天又问了一次。

预期：应识别出「给客户回报价」

11. 心里记挂

有个事儿我心里一直悬着，就是仓库那批货的保险还没续，回头得找王姐问问。

预期：应识别出「找王姐续保险」

12. 极度含蓄

老陈今天提的那个事，我觉得不能再拖了。

预期：模糊边界。看模型是保守返回空数组，还是硬造一条含糊的任务——两种都可以接受，但不该编造细节

13. 被动/委婉语气

如果方便的话，麻烦周四之前帮我看一眼那份合同，不着急，但最好别拖到下周。

预期：1 条 → 2026-08-27（本周四已过，看模型如何处理）

五、⭐ 假阳性陷阱（应该返回空数组或极少条目）

这几条专门测「模型会不会无中生有」。

14. 纯陈述，无任务

今天的会主要是同步一下上半年的情况。营收比去年同期涨了百分之十二，
华东区表现最好，华南稍微差一点。人员方面没什么变动，就这些。

预期：空数组 []

15. 已完成事项（过去时）

昨天已经把报销单交上去了，合同也签完了，服务器的续费上周就办好了，
邮件我也回过了。这几件事都结了。

预期：空数组。如果生成待办说明模型没理解时态

16. 别人的任务

小刘说他明天去对接物流，老王负责周五的客户接待，这两块我就不管了。

预期：边界情况。看模型是全部提取、还是识别出「不是我的事」

17. 数字干扰项

会议室改到三零一，参会的有十二个人，预算控制在四千二百块以内，
项目编号是二零二六零八一七，联系电话尾号三三七八。

预期：空数组。重点看模型会不会把「20260817」误当成日期

六、其他场景

18. 有任务但完全没提日期

记得把打印机的墨盒换了，另外把会议室的白板笔补一下。

预期：2 条，日期应回落到今天 2026-08-20

19. 中英混杂

明天的 standup 我可能会晚点到。这个 sprint 的 retro 记得排一下，
另外那个 PR 麻烦你 review 一下，deadline 是下周二。

预期：3 条，看中英混合下的识别率

20. 强口语 / 改口 / 语气词

呃…那个…就是明天，不对，是后天，后天下午我要去…嗯…去银行办对公账户那个事，
然后…哦对，还有个事儿，就是那个啥来着…哦，打印材料，那个得提前弄。

预期：2 条，日期取「后天」2026-08-22，考验模型处理改口

21. 极短输入

明天交周报。

预期：1 条 → 2026-08-21

22. 只有寒暄

好的好的，行，那就这样，辛苦了，再见。

预期：空数组
